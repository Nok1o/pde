# Стационарные исследования: единый доступ и честное сравнение

Запуск — `python main.py`. Для Дирихле и смешанных границ в 2D/3D доступны
сравнение, пространственные графики, исследование точности 1/5/10% и экспорт.
В исследовании смешанных границ отдельно задаются сетка, точка (включая
границы), число независимых повторов и бюджеты. Таблица содержит три строки
точности и время каждого метода. Пустое время означает отсутствие подтверждения,
а не нулевую стоимость. Причина хранится рядом в статусах и JSON.

## Область применимости

| Метод | 2D Дирихле | 3D Дирихле | 2D/3D Нейман + Дирихле или Робин | Чистый Нейман |
|---|---|---|---|---|
| ЛОМ | да | да | да | да, баланс и нулевое среднее |
| Обычный MC | да | да | да | нет |
| Контрольное приближение, хвосты, слои | да | нет | нет | нет |
| WoS | да | да | нет | нет |
| MC на сгущённой сетке | да | да | да | нет |

Типы сторон/граней задаются отдельно. Если в интерфейсе смешанных границ
все они выбраны как Дирихле, WoS становится доступен и там. Для чистого Неймана
поглощения нет: существующий алгоритм случайного выхода не возвращает решение.
Он явно запрещён, а не заменён другим решателем.

Это ограничения реализованных алгоритмов, а не невозможность соответствующих
математических расширений. WoS с отражением/локальным временем, перенос хвостов,
слоёв и контрольного приближения на 3D/новые границы требуют самостоятельных
выводов и проверок. В этой интеграции под прежним именем другой метод не скрывается.
Физическое время остаётся отдельным режимом; эти стационарные расширения к нему
не применяются.

## Что именно решают новые методы

Вход текущей программы — массивы `f` и граничных данных на равномерной сетке.
Расширения **не читают `exact`** и не вызывают эталон при построении оценки.
Для новых координат эти входные данные интерполируются линейно по каждой оси.
Это явная реконструкция заданных данных, а не восстановление из готового решения.
Она может вносить систематическую ошибку, особенно около разрывных границ.

### WoS в квадрате и кубе

На каждом шаге берётся максимальный шар радиуса R внутри области с центром x.
Следующая точка равномерна на его сфере. Источник оценивается в независимой
равномерной точке Y внутри шара; вклад — `−V G(x,Y) f(Y)` для положительной
функции Грина оператора `−Δ`. При U, равномерном на (0,1], радиус Y равен
`R U^(1/d)`, а вес VG:

- d=2: `−R² log(U)/4`;
- d=3: `R²(U^(−1/3)−1)/3`.

При расстоянии до границы ≤ ε точка проецируется на ближайшую грань,
добавляется g. В UI ε=10⁻⁴; для отдельного исследования можно вызвать
`solve_extended(problem, points, 'wos', walks=..., epsilon=...)`.
`points` — исходные индексы `[y,x]` или `[z,y,x]`.
SE описывает лишь случайный разброс. Погрешности ε и реконструкции данных
не исчезают при увеличении N. Прототип #19 с аналитическими функциями
`estimate_wos` сохранён; общий интерфейс использует обобщённое ядро для
табличных входных данных, в том числе в 3D.

### Сгущённая сетка и смешанные границы

Ось симметрична: `x_i=2(i/n)²` слева от середины и
`x_i=1−2(1−i/n)²` справа. Для каждого узла используются его контрольный объём
и расстояния до соседей. Вес перехода вдоль оси равен `1/(δ_i h_ij)`, где
δ_i — ширина контрольного объёма. На границе δ_i — половина крайнего интервала.

Граничное условие `∂u/∂n+κu=r` добавляет `r/δ_i` в правую часть
и `κ/δ_i` на диагональ. После деления на диагональ получаются награда,
вероятности переходов и вероятность поглощения. κ=0 даёт отражение Неймана.
В углах/рёбрах суммируются потоки всех инцидентных граней; Дирихле имеет приоритет.

Запрос остаётся в **той же физической точке** исходной сетки. Начальный узел
сгущённой сетки случайно выбирается среди соседей с весами многолинейной
интерполяции. Поэтому среднее оценивает интерполированное решение новой системы,
а не значение в другой точке с таким же индексом. Время включает реконструкцию,
подготовку оператора и пути. Прямое решение сгущённой системы используется
только в тестах.

## Протокол исследования

Бюджеты MC подбираются по пилотным запускам до половины целевой средней
относительной ошибки; допуски детерминированного ЛОМ — до полного порога. Выбранный кандидат
проверяется новой независимой серией; провал проверки не запускает повторный
подбор по её результатам. Точность — среднее модулей относительных ошибок **отдельных** запусков,
не ошибка их среднего. Время — среднее время одного полного запуска.
У подбора и проверки отдельные лимиты времени на метод. Лимит проверяется между запусками, начатая траектория не обрезается:
исчерпание её собственного лимита даёт отказ без численного ответа.

Основной эталон — аналитическое решение, если известно. Иначе используется
прямое решение исходной равномерной системы: это сеточный ориентир, а не
доказательство точности к непрерывной PDE. Отклонение WoS/сгущённой сетки от
равномерного эталона не называется невязкой их собственной системы.
При нулевом эталоне относительный процент не определён; исследование возвращает
статус, а сравнение продолжает показывать абсолютную RMSE.

## Воспроизведение

```sh
python -m pdelab.boundary_cli study --n 8 --left neumann --repeats 5
python -m pdelab.boundary_cli3d study --n 8 --x0 robin --repeats 5
python -m pdelab.cli3d study --n 8 --methods lod_serial mc graded wos
python -m benchmarks.stationary_integration
```

Фиксированные бюджеты последней команды дают серии «ошибка — стоимость»,
а не подтверждённую таблицу достижения порогов. Сохраняются все повторы и seed.
Не следует выбирать только лучший seed или исключать несошедшиеся запуски.
Сгущение и WoS — альтернативные схемы, а не обещание универсального ускорения.

## Зафиксированный контроль интеграции

Серия `benchmarks.stationary_integration` от 10 ноября 2026 сохраняет
[272 строки отдельных запусков](../benchmarks/results/stationary-integration/trials.csv)
и [сводку](../benchmarks/results/stationary-integration/summary.csv): сетки 8/16,
N=256/1024, четыре независимых повтора, центр области. Для Дирихле взят синус,
для смешанных границ — гладкий пример с Робином на одной стороне/грани.

На этом наборе новые схемы не превосходят обычный MC при одинаковом бюджете.
Это отрицательный результат, а не повод менять seed или скрывать строки.
Сравнение времён при разных ошибках не устанавливает победителя: для этого
нужна вкладка достижения заданного порога и её независимая контрольная серия.
Четырёх повторов недостаточно для универсальных статистических выводов.
Абсолютные времена зависят от компьютера и нагрузки.
