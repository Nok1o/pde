# Нулевой эталон в прежних исследованиях 2D

При нулевой норме эталона цели 1/5/10% неприменимы. Стационарное
исследование 2D, смешанные границы, линейная и нелинейная теплопроводность
теперь выполняют одну серию на первом заданном бюджете и показывают среднюю
абсолютную L2-ошибку отдельных полных запусков. Для одной точки это среднее
`abs(u_run − u_reference)`. Время достижения процентной цели остаётся пустым;
статус — `relative_target_not_applicable`. Абсолютная ошибка не сравнивается
с числами 1/5/10 и не запускает подбор следующего бюджета.

Серия использует отдельный индекс случайной фазы `absolute_diagnostic`.
Если нулевой эталон впервые обнаружен внутри сравнения с численным эталоном,
сохраняется фактически использованная первая фаза. Новая контрольная серия
для процентной цели не проводится. Точное решение не передаётся решателю
для построения ответа.

При отказе сохраняются записи попыток, бюджет, причина и затраченное время.
Неполная серия не получает среднюю абсолютную ошибку завершённого расчёта.
Отдельная успешная попытка остаётся в данных. У старых ядер часть исключений
не содержит числа фактических путей/переходов или памяти: такие поля отмечены
как неизвестные, а не нулевые. Для теплового исключения измеряется время
вызова; успешный запуск сохраняет собственный таймер решателя. Эти затраты
не являются временем подтверждённого достижения точности.

Ненулевые прежние исследования сохраняют свой адаптивный протокол
`stable_pilot_adaptive_retry_v6` и относительную L1-метрику области.
Новая абсолютная метрика подписана отдельно как `mean_run_absolute_l2_v1`.
Исторические результаты не переименовываются. Современное исследование 3D
уже использует общий протокол фиксированного бюджета, относительную L2-ошибку
и отдельную абсолютную диагностику при нулевой норме.

Проверки включают нулевые условия на каждой стороне тепловой задачи,
несколько старых MC-методов, смешанные границы, аналитический и численный
нулевой эталон нелинейной задачи, полные и прерванные серии, CSV и отображение
абсолютной ошибки в интерфейсе. Обычные ненулевые серии проверяются прежними
тестами подбора и независимых случайных потоков.

Пример через публичный API из окружения проекта:

```python
from pdelab.heat import make_heat_problem
from pdelab.heat_mc_study import export_heat_mc_study, heat_mc_study

study = heat_mc_study(
    make_heat_problem("decay", n=8),
    T=0.02,
    point=(0, 4),
    repeats=5,
    max_walks=64,
    methods=("lod", "mc", "mc_control"),
)
export_heat_mc_study(study, "runs/heat-zero-reference")
```
