# Единое сравнение при точности 1%, 5% и 10%

[Один файл PDF](comparison.pdf) · [полные таблицы Markdown](comparison.md) · [нормализованные данные](comparison.json).

47 сценариев, 723 строки целей: успешные сравнения, проигрыши и отказы.
Разные семейства задач, версии и протоколы отделены; отношения времени
вычисляются только внутри одной серии при подтверждении цели обоими методами.

Новая стационарная серия проведена по [опубликованному плану](../../plans/scenario-comparison.json)
на чистом commit `c474bc4049da3ffaae2139a4e47477be450a452b` после слияния PR #58.
Семь сценариев, шесть методов, R=10: все 2503 попытки завершены;
подтверждено 99 из 126 целей. Неподтверждённая цель отличается от отказа решателя:
например, на n=64 ЛОМ для 1% исчерпал общий лимит времени предварительной фазы,
завершив 9 из запланированных 10 запусков без ошибки решателя.

Измерения выполнялись последовательно в свежем процессе на сценарий, в один поток.
Все исходники и планы совпадают до и после серии; [манифест](raw/manifest.json),
[план](raw/plan.json), [SHA256](raw-sha256.json) и все исходные попытки сохранены.
Независимо пересчитаны ошибки всех 2503 векторов, бюджеты, статусы и отношения времени.
Максимальное расхождение пересчитанной ошибки — 4,97·10⁻¹⁴ процентного пункта.

В таблицах среднее время полного запуска после прогрева, включая подготовку метода.
Общие входные массивы, эталон, JIT и экспорт исключены. Все попытки новой серии
в сумме заняли 126,971458 с времени решателей; не суммируйте строки целей,
которые используют одну и ту же финальную серию. Свежая серия не подбиралась
повторно после просмотра результатов; ограниченный список бюджетов не является
поиском глобального оптимума. Мелкие различия времени не означают устойчивого выигрыша.

## Воспроизведение

Новая численная серия (выходной каталог должен отсутствовать):

```bash
python -m benchmarks.scenario_comparison --output runs/my-comparison
```

Пересборка общего файла из уже сохранённых данных, без решателей:

```bash
python -m benchmarks.scenario_report
python -m benchmarks.scenario_report --pdf
```

Для необязательной PDF-сборки нужен `reportlab` и шрифты Arial в стандартном
каталоге macOS. Работа программы и пересборка JSON/Markdown от них не зависят.
PDF с встроенными шрифтами уже сохранён и открывается на других платформах.
Исторические RMS-архивы и фиксированные бюджеты без независимой проверки цели
не выдаются за новые результаты средней относительной ошибки.
