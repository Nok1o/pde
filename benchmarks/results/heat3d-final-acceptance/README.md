закреплённый Python 3.13.14. Это функциональная проверка, её времена
не используются для выводов о производительности. [Сводка](acceptance.json)
содержит фактические настройки и статусы; рядом сохранены все UI/CLI-выгрузки

Выполнен настоящий Streamlit-сценарий через AppTest: выбор режима в `app.py`,
изменение виджетов, нажатие кнопок расчёта/исследования, чтение скачиваемых
данных. Каждая команда воспроизведения из сохранённого результата исполнена
отдельным CLI-процессом. Сверены настройки, значения, seed, статусы и
счётчики; времена разных запусков не сравнивались на равенство.
Изменение параметров оставляет сохранённый результат с прежними настройками.
Повторная отрисовка с пояснениями также сохраняет его.

совпадение результата и честного статуса между поверхностями. CLI завершился
с кодом 2 там, где была неподтверждённая цель или отказ; выгрузки сохранены.

Полный набор объединённой версии: **1334 теста прошли**, включая старт
`python main.py` из другого каталога. Ruff и Black прошли. Все 188
конфигураций финального плана проверены через опубликованные параметры API.

Воспроизведение функционального сценария из чистого checkout:


и не повторяет численные отказы ради успешного результата.
