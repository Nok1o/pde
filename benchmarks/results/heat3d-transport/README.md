# Перенос количеств частиц и весов: исходные данные

[Единый отчёт: сравнение, графики и ограничения](../../heat3d-transport-report.md).
[План до измерений](../../heat3d-transport-plan.md).

Измеренный commit: `ec12d1ebececffea430e81863f6318ea7b77c3b9`,
26 ноября 2026 года, Python 3.13.14, один поток, последовательные процессы.
Новые `mc_counts` и `mass_transport` не заменяют исторические результаты
прежнего `mc_grouped`.

- `frozen-n8/`: 8 заданий, одна замороженная система, независимый прямой
  сеточный эталон. 170/170 полных попыток, 24/24 подтверждённых целей.
- `full-n8/`: 16 заданий полной нелинейной истории; 244/270 полных попыток,
  26 отказов по итерациям, 39/48 подтверждённых целей.
- `full-n16/`: 8 заданий полной истории; 71/115 полных попыток, 38 отказов
  по итерациям, 6 по времени, 18/24 подтверждённых целей.
- [cost-decision.json](cost-decision.json): разрешение n=16 записано до его
  запуска; суммарные затраты всех попыток n=8 — 10,658231 с при пороге 120 с.
- [raw-sha256.json](raw-sha256.json): SHA256 всех исходных файлов, включая
  манифесты, экспорты, журналы, планы и решение по стоимости. Копии проверены
  побайтово относительно первоначального каталога запуска.

Производные файлы в корне: [все цели](targets.csv), [все попытки](trials.csv),
[этапы](stages.csv), [итоги](totals.json), полные таблицы
[frozen](one_frozen_system.md) и [full](complete_nonlinear_history.md),
графики. Они не входят в каталог SHA256 исходных данных и пересобираются без
запуска решателей:

```sh
.venv/bin/python -m benchmarks.heat3d_transport_report \
  --root benchmarks/results/heat3d-transport
```

Суммировать затраты следует по `trials.csv`: строки разных целей могут
переиспользовать одну финальную серию. Неполные серии сохранены со статусом
отказа и не выданы за решение. Показатели неприменимости/неизвестной памяти
в сводке обозначены пустым значением; исходные экспорты не исправлялись.

В `targets.csv` поле `seconds` — среднее время подтверждённой цели,
`preparation_seconds` и `construction_seconds` — суммы выбранной серии,
`mean_preparation_seconds` и `mean_construction_seconds` — средние на
записанную попытку. Эти средние учитывают затраты отказов. Поля неприменимой
сборки полной истории остаются пустыми; её детализация доступна в
`assembly_seconds` и `factorization_seconds` с исходным смыслом API.
